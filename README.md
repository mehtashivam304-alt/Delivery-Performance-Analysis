# Delivery Performance Analysis

 Project Overview
 An interactive Power BI project to analyze delivery performance, delays, delivery costs, customer ratings, and operational efficiency.

 Tools & Technologies
 PostgreSQL
 Power BI
 DAX
 SQL
 
 Dashboard Pages
 Executive Overview
 Total and delayed deliveries
 Average delivery cost and rating
 Regional performance
 Delivery status distributins

 Delay Analysis
 Delay Rate and On-Time Delivery KPIs
 Delays by weather condition
 Delivery mode and vehicle type analysis
 Delivery partner performance

 Cost & Operations
 Average delivery cost by region
 Average rating by delivery partner- Cost by distance range
 Cost by package type

 Key Insights
 Stormy weather recorded the highest number of delayed deliveries in the dataset.
 Express delivery showed a higher delay rate in the dashboard.
 The dashboard reported a 73.32% on-time delivery rate and a 26.68% delay rate in the displayed view.

Note: Results may vary with dashboard filters.
